# WebGLヒーロー歪みエフェクト — 設計

## 背景・目的

[vlag.yokohama](https://vlag.yokohama/) のヒーローセクションを参考に、Ikitaria本体サイトとAlmanaccoサイト両方のヒーローに、WebGL(Three.js)による本格的な歪み・流動エフェクトを導入する。

**方針**: vlag.yokohama固有のコード・画像・ロゴをそのまま流用しない。技術パターン(Three.js + simplex noiseによる歪みシェーダー)を参考に、両サイト独自の素材で新規実装する。

## vlag.yokohamaの技術調査結果

- Three.jsを使用(ミニファイされたJS内に大量のThree.js標準uniform名を確認)
- カスタムシェーダーに `snoise`（simplex noise関数）、`uProgress`、`distortion` という識別子があり、simplex noiseベースのUV座標歪みで画像を流動的に見せる、比較的よく知られたWebGL実装パターンであることを確認
- レイアウトは、写真3枚を横に並べたパネルの中央に、大きな装飾ロゴマークを重ねる構成

## デザイン

### レイアウト(両サイト共通パターン)

3分割された画像パネルの中央に、ブランドマークを大きく重ねる構成。

- **Ikitaria**: 現在のヒーロー写真(torii + 富士山+ オリーブの木、`images/5805513934478887111.jpg`)を横3分割にクロップしてパネル化。中央に「IKITARIA」のテキストロゴを大きくタイポグラフィとして重ねる（新規シンボルマーク素材は作成しない）。
- **Almanacco**: 現在のヒーロー背景イラスト(`hero-map-motif.jpg`)を横3分割にクロップしてパネル化。中央に既存の燕マーク(`logo-swallow.png`)を大きく重ねる。

### WebGLエフェクト

- Three.jsで各パネルを平面ジオメトリ + 画像テクスチャとしてレンダリング。
- フラグメントシェーダーでsimplex noiseを使い、UV座標を時間経過で緩やかに歪ませる（"ユラユラ"する流動効果）。
- 強度は控えめに（vlag.yokohamaのような目立つ歪みではなく、ゆったり揺れる程度）。既存の`hero-drift`（ゆっくりズーム）と併用可能な強さに調整する。

### フォールバック・アクセシビリティ

- `prefers-reduced-motion: reduce` を検知した場合、WebGL自体を初期化せず、静止画（3分割パネルをそのままCSSで並べたもの）を表示する。
- WebGL非対応ブラウザ（`canvas.getContext('webgl')` が失敗するケース）でも同様に静止画にフォールバックする。
- WebGL初期化前は必ず静止画（3分割パネル）がSSR/静的HTMLとして存在し、JSが正常に動けばcanvasに置き換える「プログレッシブエンハンスメント」の形にする（初期表示が真っ白にならないようにする）。

## 技術選定

- **ライブラリ**: Three.js
- **Almanacco**: `npm install three` で `almanacco-src` の依存に追加。
- **Ikitaria本体**: ビルドシステムがない静的サイトのため、CDN経由（jsdelivrまたはunpkg）で読み込む。前例（GSAP導入時）に倣い、正確なバージョンを指定し、Subresource Integrity（SRI）ハッシュを付与してサプライチェーン対策を行う。

## スコープ外

- vlag.yokohama固有のコード・画像・ロゴの流用（著作権上、行わない）。
- ヒーロー以外のセクションへのWebGLエフェクト適用。
- マウス追従などのインタラクティブな歪み（今回は時間経過による自動アニメーションのみ）。

## 実装順序

1. **プロトタイプ**: Almanaccoホームページのヒーローに実装し、スクリーンショット・実機での動作を確認してもらう。
2. 承認後、Ikitaria本体のヒーロー（`index.html` 含む全言語のHomeページ、共通コンポーネントのため実質1箇所の実装で全ページに反映）に展開。
3. 各段階でモバイル・デスクトップ、`prefers-reduced-motion` 有効時の両方を確認する。
