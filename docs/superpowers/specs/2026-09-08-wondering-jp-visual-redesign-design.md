# Wondering.jp風ビジュアルリデザイン — 設計

## 背景・目的

Ikitaria本体サイト（静的HTML、約30ページ、3言語）とAlmanaccoサイト（Astro、3言語）のビジュアルデザインを、参考サイト [wondering.jp](https://wondering.jp/)（北海道のライフスタイルストア）を参考に刷新する。

**方針**: テキスト内容・情報構成（何がどのページに書かれているか）は変更しない。変更対象は見た目（配色・タイポグラフィ・レイアウトの視覚表現）のみ。

## wondering.jpのデザイン言語（分析結果）

- **配色**: ほぼモノトーン（グレー・白・黒）。装飾的なアクセントカラーはほぼ使わず、商品写真の色だけで彩りを出す。
- **タイポグラフィ**: 見出し・本文とも大文字（uppercase）＋広めのレタースペーシング、細めのサンセリフ体。
- **レイアウト**: 余白を大きく取り、写真を中心に見せる。セクション見出しは左上に小さく配置し、右に補助リンク（"VIEW MORE"等）。
- **UI要素**: ボタンはアウトラインのみ＋矢印アイコン、角丸なし。カード・画像にドロップシャドウなど装飾的効果を使わない。

## デザイントークン

### 配色（共通ベース＋各サイトの最小限のアクセント）

両サイト共通でベースをモノトーン系グレーに統一。既存のブランドカラーは全面的に使うのではなく、"アイデンティティの最後の一滴"として、縁取り・リンクホバー等の最小限の箇所にのみ残す。

| トークン | 値 | 用途 |
|---|---|---|
| 背景 | `#F6F6F4` | ページ全体の背景 |
| サーフェス（カード等） | `#FFFFFF` | カード、フォーム背景 |
| テキスト | `#1A1A1A` | 本文・見出し |
| ミュートテキスト | `#6E6E6C` | 補助テキスト、キャプション |
| ボーダー/ライン | `#DCDCD9` | 区切り線、ボタン枠線 |
| アクセント（Ikitaria） | `#C8A864`（既存の`--gold`を維持） | CTA枠線、リンクホバー等の最小限 |
| アクセント（Almanacco） | `#233126`（既存の`--color-forest`を維持） | 同上 |

暖色系のアイボリー／クリームベース（Ikitariaの`--bg: #f5f2ec`、Almanaccoの`--color-ivory: #f4f1eb`）は廃止。

### タイポグラフィ

- 見出し・本文とも `"Outfit"`（サンセリフ）に統一。
- 廃止するセリフ体: Ikitariaの`Cormorant Garamond`/`Playfair Display`、Almanaccoの`Cinzel`/`Cormorant Garamond`。
- 見出し: `text-transform: uppercase`、`letter-spacing: 0.15〜0.2em`、`font-weight: 300〜400`。
- 本文: 通常表記、行間は現状程度の広さを維持。
- セクション見出しパターン: 小さめのkickerラベルを左上、右に補助リンク（wondering.jpの"RECOMMEND ITEMS / VIEW MORE"に相当する既存の構造は保持）。

ロゴ（テキストロゴ「IKITARIA」「ALMANACCO」）自体は変更しない。wondering.jpのような手描き線画ロゴへの変更はスコープ外。

### レイアウト・UIコンポーネント

- 余白: セクション間・要素間のpadding/marginを現状より拡大。
- ボタン（CTA）: 塗りつぶし背景を廃止し、アウトライン（1px border）＋矢印アイコン（→）のみに。角丸なし。
- カード・画像: `box-shadow`（`--shadow-card`/`--shadow-lift`等）を削除してフラットに。ボーダーは1pxのみ、または無し。
- 画像グリッド: 既存のカテゴリ／商品グリッド構造はそのまま活かし、余白と枠線のスタイルのみ調整。

## スコープ外

- テキスト内容、ページ構成、情報設計（前回の作業で確定済み）は変更しない。
- ロゴマークのビジュアル変更。
- 新規ページ・新規機能の追加。

## 実装順序

1. **プロトタイプ**: Almanaccoホームページ（`almanacco-src`、Tailwind `@theme`トークンで一元管理しやすい）に新デザイントークンを適用し、実際の見た目をスクリーンショットで確認してもらう。
2. 承認後、Almanaccoの残りページ（Shop、Home内の各セクション）に展開。
3. Ikitaria本体（`style.css`の該当CSS変数・ルールを同方針で更新）に展開。全言語・全ページに一括適用（共通CSSファイルのため、変数変更で大部分が自動反映される想定）。
4. 各段階でモバイル・デスクトップ双方の見た目を確認し、崩れがないか検証する。
